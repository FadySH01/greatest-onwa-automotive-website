# Greatest Onwa Automotive Parts Website

A responsive React and TypeScript storefront concept for browsing automotive parts. The interface includes product listings, search and filters, enquiry flows, and frequently asked questions.

## Run locally

1. Install Node.js 22.13 or newer.
2. Open this folder in VS Code and run `npm install` in the terminal.
3. Run `npm run dev` and open the local URL shown in the terminal.

To create a production build, run `npm run build`. To preview that build locally, run `npm run preview`.

## Demo scope

Product listings and reviews are illustrative. The enquiry form prepares a message for the visitor to review and send; it does not check live inventory, process payments, or send messages automatically. Confirm product fit, prices, delivery terms, and business contact details before using the site with customers.
